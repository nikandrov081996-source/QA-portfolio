# QA-portfolio
**Портфолио для хранения тестовой документации** 

Здесь будут храниться:
- тест-планы;
- чек-листы;
- тест-кейсы;
- баг-репорты;
- отчёты о проведении тестирования;
- файлы коллекции API тестов;
- различные вложения и тестовые данные, которые понадобились для проведения тестирования.
